# SATIT GLORY League

เว็บจัดการ SATIT GLORY League Season 2 พร้อม API สำหรับซิงก์คะแนน โปรแกรม สถานะการแข่งขัน ประกาศ โปสเตอร์ และข้อมูลผู้เล่นระหว่างทุกอุปกรณ์ รวมถึงกล่องข้อความส่วนตัวสำหรับผู้จัด

## Deploy ให้มีเซิร์ฟเวอร์และข้อมูลถาวร

เว็บนี้ต้องรัน Node.js server; GitHub Pages ใช้ API และบันทึกข้อมูลไม่ได้

1. Push branch หรือ merge PR นี้เข้าที่เก็บ GitHub
2. สร้าง Web Service จาก repository นี้บน Render โดยใช้ Blueprint ใน `render.yaml`
3. ตั้งค่า secret `ADMIN_PASSWORD` ในหน้าสร้างบริการ เป็นรหัสผ่านยาวอย่างน้อย 16 ตัวอักษร ห้ามใส่รหัสผ่านในไฟล์หรือในหน้าเว็บ
4. รอ deploy เสร็จ แล้วเปิด URL ที่ Render ให้มาเพื่อใช้งาน หน้าเว็บจะแสดงสถานะเชื่อมต่อเซิร์ฟเวอร์ที่ส่วนท้าย
5. กดปุ่มเฟืองเพื่อเข้าสู่ Admin Mode ด้วยรหัสผ่านที่ตั้งไว้

Blueprint ใช้ persistent disk สำหรับข้อมูลลีก ดังนั้นบริการอาจมีค่าใช้จ่ายตามแผน Render ที่เลือก โปรดตรวจราคาและแผนก่อนยืนยันการสร้างบริการ หากใช้โฮสต์อื่น ให้รัน `npm start`, ตั้ง `ADMIN_PASSWORD` และกำหนด `DATA_DIR` ไปยังโฟลเดอร์ที่เก็บข้อมูลถาวรของโฮสต์นั้น

## รันในเครื่อง

ต้องใช้ Node.js 20 ขึ้นไป:

```sh
npm start
```

PowerShell ก่อนเริ่มเซิร์ฟเวอร์:

```powershell
$env:ADMIN_PASSWORD = "ตั้งรหัสผ่านยาวอย่างน้อย 16 ตัวอักษร"
npm start
```

เปิด http://localhost:3000

## การทำงานและความปลอดภัย

- ข้อมูลหน้าเว็บถูกอ่านจาก `GET /api/state` และผู้ดูแลบันทึกผ่าน `PUT /api/state`
- ผู้ใช้ส่งคำสั่งเครื่องดื่ม ขอเพลง และสมัครรายการผ่าน `POST /api/messages`; ผู้ดูแลดูข้อความได้หลังล็อกอิน
- รหัสผ่านผู้ดูแลอยู่ใน environment ของเซิร์ฟเวอร์เท่านั้น และใช้ session cookie แบบ HttpOnly, SameSite
- ใช้ไฟล์ `league-state.json` ใน `DATA_DIR`; ตั้งโฟลเดอร์นี้เป็น persistent disk เพื่อไม่ให้ข้อมูลหายเมื่อ deploy ใหม่
- API จำกัดขนาดข้อมูลและจำนวนคำขอบางชนิด และตรวจสอบ same-origin สำหรับการเขียนข้อมูล
- ไม่ควรนำ API นี้ไปเปิดใช้งานแบบหลายผู้ดูแลพร้อมกันโดยไม่เพิ่มระบบสำรองข้อมูลและการควบคุมสิทธิ์เพิ่มเติม
